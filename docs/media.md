# Υλικό του site — από πού βγήκε και πώς

Τα πρωτότυπα **δεν** είναι στο repo: είναι εκατοντάδες MB και δεν έχουν λόγο να
βαραίνουν κάθε clone και κάθε deploy. Βρίσκονται στο `Desktop/Casa Playa Content/`.
Εδώ γράφονται οι ακριβείς εντολές, ώστε οποιοδήποτε αρχείο να ξαναφτιάχνεται ή να
αλλάζει χωρίς μαντεψιές.

## Βίντεο φόντου στην αρχική

Πηγή: `Casa Playa Reels/9.mov` — 1440×2560, 12,2″, H.264, **25 MB**.

Δύο πράγματα το κάνουν ακατάλληλο ως έχει:

1. Είναι **κολάζ τριών πλάνων στοιβαγμένων κάθετα**, φτιαγμένο για Instagram Reels.
   Σε οθόνη landscape το `object-fit: cover` θα έδειχνε μια στενή λωρίδα πάνω στη
   ραφή ανάμεσα σε δύο πλάνα.
2. 25 MB για φόντο σελίδας είναι απαγορευτικό σε δεδομένα κινητού.

Λύση: **κόβεται το μεσαίο πλάνο** (η παραλία με τις cabanas και τις ξαπλώστρες),
που δίνει κανονικό landscape 1440×852, και ξανακωδικοποιείται. Αποτέλεσμα ~1 MB.

Τα τρία πλάνα βρίσκονται στα `y=0`, `y=853`, `y=1706` (2560 ÷ 3).

```bash
SRC="Casa Playa Reels/9.mov"
CROP="crop=1440:852:0:853,scale=1280:-2"      # 853 = μεσαίο πλάνο

ffmpeg -i "$SRC" -vf "$CROP" -an \
  -c:v libx264 -crf 30 -preset slow -pix_fmt yuv420p -movflags +faststart \
  public/video/hero.mp4

ffmpeg -i "$SRC" -vf "$CROP" -an \
  -c:v libvpx-vp9 -crf 40 -b:v 0 -row-mt 1 -deadline good -cpu-used 2 \
  public/video/hero.webm

ffmpeg -ss 5 -i "$SRC" -vframes 1 -vf "$CROP" -q:v 6 \
  public/video/hero-poster.jpg
```

- `-an` αφαιρεί τον ήχο: το autoplay απαιτεί σίγαση ούτως ή άλλως, και γλιτώνουμε όγκο.
- `-movflags +faststart` βάζει τα μεταδεδομένα στην αρχή, ώστε να ξεκινά η
  αναπαραγωγή πριν κατέβει όλο το αρχείο.
- Το poster είναι το πρώτο πράγμα που φαίνεται και το μόνο που κατεβαίνει όταν ο
  browser παραλείψει το βίντεο.

**Για άλλο πλάνο**: άλλαξε το offset στο `crop` (`0` πάνω, `853` μεσαίο, `1706` κάτω).
**Για τελείως άλλο υλικό**: το `Casa Playa Reels/7 - horizontal.mov` είναι εγγενώς
οριζόντιο (2560×1440, 35″) και δεν χρειάζεται κόψιμο — μόνο κλιμάκωση.

## Φωτογραφίες προϊόντων

Πηγή: `New Photos Casa Playa/`, αρχεία 2048×1536.

```bash
ffmpeg -i "New Photos Casa Playa/<NNN>_(2048).jpg" -vf "scale=1600:-1" -q:v 4 \
  public/products/<slug>.jpg
```

| Προϊόν (`slug`) | Αρχείο |
|---|---|
| `cabana-beach-bed-1st-row` | `010_(2048).jpg` |
| `seaside-sun-bed-1st-row` | `050_(2048).jpg` |
| `seaside-sun-bed-2nd-row` | `051_(2048).jpg` |
| `seaside-sun-bed-3rd-row` | `051_(2048).jpg` |
| `private-restaurant-area` | `008_(2048).jpg` |
| `restaurant-area` | `045_(2048).jpg` |

> Η **2η και η 3η σειρά μοιράζονται την ίδια φωτογραφία** — έτσι δόθηκε η
> αντιστοίχιση. Αν θέλουμε να ξεχωρίζουν, το `052_(2048).jpg` είναι διαθέσιμο και
> δείχνει επίσης σειρά ξαπλώστρων.

Οι διαδρομές δηλώνονται στο `src/data/catalog.ts` (`imageUrl`) και περνούν στη βάση
με `npm run db:seed`. Αλλαγή φωτογραφίας = αντικατάσταση του αρχείου με το ίδιο
όνομα· δεν χρειάζεται νέο seed αν το `slug` δεν αλλάζει.
